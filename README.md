**Real-Time Chat App** – Node.js, Express, Socket.io, HTML/CSS/JS
- Built a real-time web chat application enabling users to send and receive messages instantly using WebSocket communication via Socket.io.
- Implemented user join/leave notifications and message broadcasting to multiple clients in real-time.
- Managed server-side events and client-side rendering for a seamless messaging experience.
- Deployed app on Render.
- Continuing to add features in the coming weeks, including authentication, stored chat logs in MongoDB and more.
